# Food Delivery Application

A full-stack food delivery application built using the MERN Stack.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## Project Structure
- frontend: React frontend application
- backend: Node.js and Express backend

## Features
- User authentication
- Restaurant and food management
- Cart and checkout
- Order management

## Installation

Clone the repository:

```bash
git clone https://github.com/ajeetkushwaha61aa-create/food-delivery-mern.git
```

Install dependencies inside the frontend and backend folders using npm install.
